# RHEVIX — Empower Your Digital Transformation

> **A global platform connecting exceptional developers, AI engineers, researchers, designers, scientists, analysts, and domain experts with companies building the future of AI.**

---

## Overview

**RHEVIX** is a production-quality, editorial AI talent platform inspired by high-density technical publications, frontier AI infrastructure companies, and elite talent marketplaces. 

Predominantly light, calm, and high-contrast, the platform features a living multi-layer AI background ecosystem, smooth 60fps scrolling, and an interactive opportunity marketplace for frontier contracts.

---

## Key Features

- **Living AI Intelligence Network (5 Background Layers)**:
  - **Layer A (Intelligent Grid)**: Ultra-thin technical grid lines (`0.035` opacity) with scroll parallax.
  - **Layer B (Connected AI Nodes)**: Canvas-based floating nodes forming dynamic proximity connections.
  - **Layer C (Data Flow Packets)**: Continuous data packets traveling along active network pathways.
  - **Layer D (Soft Atmospheric Light)**: Ambient blurred light washes (deep blue, indigo, soft cyan) at `3–5%` opacity.
  - **Layer E (Expertise Signals)**: Peripheral technical tokens (`AI`, `LLM`, `RESEARCH`, `PYTHON`, `ROBOTICS`, `SYSTEMS`).
  - **Subconscious Parallax**: Natural 3–5px displacement on cursor movement (disabled on mobile).
- **Interactive Hero AI Network Topology**: Central breathing RHEVIX core node routing verified capabilities into active contract compensation milestones.
- **Continuous Opportunity Ticker**: 50% CSS linear transform marquee featuring live compensation rates with hover-pause.
- **Editorial Technology Magazine Section**: Verified luminary profiles (e.g. Dr. Elena Vance, Marcus Thorne) with studio portraits and peer-reviewed credentials.
- **Domain Taxonomies**: 12 interactive discipline categories with live opportunity counters.
- **Opportunity Marketplace**: Searchable filter tabs (`All`, `AI`, `Engineering`, `Data`, `Research`, `Design`, `Science`) with single-click detailed requirement drawers.
- **Interactive Modals**:
  - `TalentApplyModal`: 3-step credentialing and calibration onboarding.
  - `EnterpriseHireModal`: Rapid 48h talent sourcing brief.
  - `OpportunityDetailModal`: Full role specifications with instant application trigger.
  - `ExpertStoryModal`: Simulated audio dispatch player with interactive waveform.
- **Lenis Smooth Scrolling**: Controlled 60fps fluid scrolling across the entire homepage.
- **Full Accessibility**: Respects `prefers-reduced-motion` with an interactive motion toggle switch in the navbar.

## Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **Library**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Smooth Scroll**: [Lenis](https://github.com/darkroomengineering/lenis)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: [Geist & Geist Mono](https://vercel.com/font)

## Getting Started

### 1. Clone & Install

```bash
git clone https://github.com/anmolghost6789/rhevix.git
cd rhevix
npm install
```

### 2. Run Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port indicated in your terminal) in your browser.

### 3. Production Build

```bash
npm run build
npm start
```
